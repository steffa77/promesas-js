# Tarea 07: Promesas en JavaScript

## Descripción general

En esta tarea se desarrollan cuatro ejercicios utilizando HTML y JavaScript para consumir APIs mediante `fetch`. Se utilizan funciones asíncronas con `async/await`, manejo de errores con `try/catch` y eventos de formularios para buscar información según un ID ingresado por el usuario.

## Ejercicio 1: Búsqueda de planetas

Este ejercicio permite buscar un planeta del universo de Star Wars mediante su identificador (ID). Utiliza la API SWAPI para obtener y mostrar cinco datos: nombre, clima, terreno, gravedad y población. También informa cuando el planeta solicitado no existe.

## Ejercicio 2: Búsqueda de naves espaciales

Este ejercicio permite consultar una nave espacial de Star Wars ingresando su ID. Obtiene información de la API SWAPI y muestra el nombre, modelo, fabricante, tripulación y clase de la nave. Si no encuentra la nave, muestra un mensaje de aviso.

## Ejercicio 3: Búsqueda de personajes de Dragon Ball

Este ejercicio permite buscar personajes de Dragon Ball por su ID. Utiliza una API de Dragon Ball para obtener el nombre, la descripción y la imagen del personaje. También contempla el manejo de errores cuando la consulta no se realiza correctamente.

## Ejercicio 4: Búsqueda de Pokémon

Este ejercicio permite buscar un Pokémon mediante su ID. Utiliza PokéAPI para mostrar el nombre, la altura, el peso y la imagen del Pokémon seleccionado.

## Tecnologías utilizadas

- HTML5
- JavaScript
- Fetch API
- Async/await
- Try/catch
- APIs REST
